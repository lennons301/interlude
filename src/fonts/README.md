# Self-hosted fonts

IBM Plex Sans and IBM Plex Mono (latin subset, weights 400/500/600), taken
from the [@fontsource](https://fontsource.org) builds of the official IBM
Plex release. Self-hosted so the dashboard makes no CDN requests at build or
runtime (issue #21).
